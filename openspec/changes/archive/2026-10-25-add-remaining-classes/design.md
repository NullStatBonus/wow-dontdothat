## Context

Hunter and Paladin set the pattern: `Rules/Data/<Class>.lua` (specs, rotations, tags, reasons, overrides, `talentSpells`, `reviewed`, optional `milestones`), a bundled spell table from `tools/build-spell-data.py`, and a test that every spell family has been considered. Class names, spells, talents and tab order for all seven classes are in the local cache `tools/.cache/class-spells.json` (WoW Forever 1.60.1.70532 and Classic Era 1.15.9.70003, from wago.tools). The tables show what a class can have, not what its trainer sells or charges, so every rotation is `needsReview` and prices stay estimates until trainers are captured with `/ddt export`.

## Goals / Non-Goals

**Goals:** every spell family of every remaining class classified on purpose; rank skips only where the data supports them; the Warlock mount perk and grimoire rule.

**Non-Goals:** rune and engraving abilities, pet and demon spells that are not class abilities, rank skips without data, profession and weapon-skill advice.

## Decisions

1. **Same shape per class.** Specs follow the verified tab order: Mage Arcane, Fire, Frost; Warlock Affliction, Demonology, Destruction; Priest Discipline, Holy, Shadow; Druid Balance, Feral, Restoration; Shaman Elemental, Enhancement, Restoration; Rogue Assassination, Combat, Subtlety; Warrior Arms, Fury, Protection. Spec keys are three-to-four letter codes, trees 1, 2, 3.
2. **Criteria.** Core = the brief's "train only" plus the spec's staples (rotation `core`, per spec). Informational = handy now and then (`situational`). PvP (defer-low-value) = crowd control and anti-player tools. Group (defer) = group or raid buffs, resistances, group heals, battle resurrection. Endgame (defer) = level 50+ spells that need reagents, portals and rituals. Low value (defer-low-value) = the brief's "skip entirely", detection, tracking and travel toys. Everything else is "reviewed and kept". Because rotation membership is checked before tags, a spell meant to be skipped is never listed in a rotation.
3. **Talent spells from the data.** Each class's `talentSpells` is the set of spell families that are also talents of the same name (for example Mage: Ice Barrier, Pyroblast, Blast Wave, Combustion, Ice Block; Warlock: Siphon Life, Shadowburn, Conflagrate; Priest: Mind Flay, Holy Nova, Vampiric Embrace, Power Infusion, Lightwell, Divine Spirit; Druid: Nature's Grasp, Insect Swarm, Moonkin Form; Shaman: Stormstrike, Mana Tide Totem, Weapon Mastery; Rogue: Hemorrhage; Warrior: Mortal Strike, Bloodthirst, Shield Slam). The tasks generate them by intersecting the cache.
4. **Rank skips (data-checked).** Higher ranks of Psychic Scream (8s fear), Gouge (4s), Kick (5s), Shield Bash (6s) change only mana or minor damage, so `skipRanks` = Psychic Scream {2,3,4}, Gouge {2,3,4,5}, Kick {2,3,4}, Shield Bash {2,3}. No skip for: Fear (10, 15, 20s), Entangling Roots (12 to 27s), Hibernate (20 to 40s), Shackle Undead (30 to 50s), Demoralizing Shout (attack power reduction about 4 times larger), Fade (threat reduction grows), Healing Wave (39 to 1615) or Chain Lightning. "Keep Frostbolt and Frost Nova at rank 1 on your bars" is an action-bar tip and produces no rule.

6. **Grimoires.** The game data lists 15 real demon-trainer grimoire families as item class 9 (Recipe) subclass 0 (Book): Imp Blood Pact, Fire Shield, Firebolt, Phase Shift; Voidwalker Consume Shadows, Sacrifice, Suffering, Torment; Succubus Lash of Pain, Seduction, Soothing Kiss; Felhunter Devour Magic, Paranoia, Spell Lock, Tainted Blood. They fall in the Recipes category, which defaults to the auction house only, so demon trainer purchases are never flagged today. Warlock data gets `grimoires = { keep = { "Firebolt", "Torment" }, reason = "Secondary demon abilities can wait." }`. `ItemGuard.Inspect` reads the item name from the link, and for a Warlock matches `Grimoire of <family>`; a family not in `keep` is flagged on the vendor surface, then follows the minimum price, Shopping switch and ask-before-buying exactly like other items. Firebolt and Torment stay kept because they are the Imp's and Voidwalker's main abilities, and the player's pet is not known.
7. **Warlock mount.** Summon Felsteed is taught by a free quest that also teaches Apprentice Riding (Warcraft Tavern); the Dreadsteed also grants Journeyman Riding. Level 40 target `{ riding = 0, mount = 0, note = "Your Felsteed is paid for in souls, not gold." }`; level 60 stays at the default. A zero target hides the progress line, as designed.
8. **Generator.** `tools/build-spell-data.py` gets a per-class configuration (mask, class skill lines, effect-name prefixes) for all nine classes and keeps `--keep` for blocks that came from trainer exports. Rows in the Runes, Engraving, Racial and generic skill lines are excluded. Price estimates borrow Hunter's table, UNVERIFIED.

## Risks / Trade-offs

- **Judgement calls at scale:** about 600 spell families are classified by my reading of the brief and general Classic knowledge, not by a sourced guide. Every rotation is flagged needs-review, and the default for the unsure is "keep".
- **Forever-only spells** (for example Arcane Blast, Ice Lance, Frostfire Bolt, Lava Burst, Riptide, Penance, Mutilate, Victory Rush) are classified by name and guess; they are the least certain rows.
- **Brief and data disagree** in several places (decision 4); the data wins, and the skips left out can be added later with evidence.
- **Grimoire matching by name** depends on the item link text; if a client words it differently, the rule does nothing, which fails safe.
- **Size:** seven classes in one change is large; tasks are grouped per class so each can be checked on its own.
