Updating
1. Download the upstream tarball for the new commit into an empty scratch directory.
2. Replace each file under DontDoThat/Libs with the upstream file of the same path. Do not add modules.
3. Compare hashes (shasum -a 256) with the tarball and with Closest Vendor and KeepThat: every file the addons share
   must be identical. Update them in the same round.
4. Update the commit line and every MAJOR, MINOR and widget version above from the new files.
5. Run make test and make check, then open the settings window on Classic Era and WoW Forever.
